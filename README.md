# WORKPLAN — Kampus Planner (frontend)

Frontend statis (HTML/CSS/JS vanilla) untuk WORKPLAN. Backend: Google Apps Script (REST API JSON).

- Ubah **hanya** `js/config.js` → isi `GAS_URL` dengan URL Web App `/exec`.
- Deploy: GitHub Pages → Settings → Pages → branch `main` / root → Enforce HTTPS.
- Panduan lengkap: lihat `PANDUAN_DEPLOYMENT.md` di paket WORKPLAN.

Struktur: `index.html`, `css/style.css`, `js/` (config, icons, stat, core, pages, modules, app), `sw.js`, `manifest.webmanifest`, `icon.svg`.
